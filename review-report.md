Отчет по код-ревью (Clean Code)

Категория: JavaScript (app.js)
Место в коде: Объявление функций createNewTaskElement, addTask, editTask, deleteTask и других (const func = function() {}).Проблема: Использование устаревшего синтаксиса функциональных выражений. Современные стандарты JS (ES6+) рекомендуют использовать стрелочные функции для анонимных функций или классическое объявление через ключевое слово function для именованных.Условие: Проявляется при чтении кода, снижает его лаконичность и соответствие современным стандартам (Modern JS).Способ проверить исправление: Переписать объявления на современный синтаксис, после чего добавить, отредактировать и удалить задачу в браузере, чтобы убедиться в сохранении работоспособности.

Место в коде: Функция addTask, условный оператор if (!taskInput.value) return;.Проблема: Отсутствие фигурных скобок у оператора if. Согласно правилам Clean Code, блоки кода всегда должны оборачиваться в фигурные скобки, даже если содержат только одну строку. Это предотвращает критические ошибки при добавлении новых строк в будущем.Условие: Проявляется при попытке другого разработчика расширить условие новой строкой кода — из-за отсутствия скобок новая строка выполнится вне зависимости от условия.Способ проверить исправление: Обернуть return в фигурные скобки, сохранить файл, проверить, что пустые задачи по-прежнему не добавляются в список.

Категория: HTML (index.html)
Место в коде: Теги <img> (логотип матрицы Эйзенхауэра и иконки удаления ./remove.svg в каждом элементе списка).Проблема: Нарушение базовых стандартов веб-разработки (Accessibility). У изображений отсутствует обязательный атрибут альтернативного текста.Условие: Проявляется в случаях, когда картинка не может быть загружена сервером, а также при использовании приложения людьми с нарушениями зрения (скринридеры не смогут прочитать, что изображено на кнопке).Способ проверить исправление: Добавить соответствующий атрибут ко всем тегам изображений, после чего проверить HTML-файл через официальный валидатор W3C (ошибка об отсутствии атрибута должна исчезнуть).

Место в коде: Тег <label> внутри списка задач (<label class="task">Pay Bills</label>).Проблема: Нецелевое использование тега. Тег <label> предназначен для связывания текста с полем ввода (через атрибут for или оборачивание инпута). В данном случае он используется просто как текстовый контейнер для названия задачи, не привязанный к чекбоксу программно.Условие: Проявляется при попытке кликнуть на текст задачи — чекбокс не переключается, так как связи между label и input type="checkbox" нет.Способ проверить исправление: Добавить уникальные идентификаторы чекбоксам и связать их с соответствующим тегом label, после чего клик по тексту задачи в браузере должен менять состояние чекбокса.

Категория: CSS (style.css)
Место в коде: Глобальные стили ul (padding: 0px;) и button (border: 0px;).Проблема: Использование единиц измерения (px) для нулевых значений. С точки зрения синтаксиса все скобки и точки с запятой расставлены верно, однако правила "чистого CSS" требуют опускать единицы измерения у нулей для уменьшения визуального шума и размера файла.Условие: Проявляется при статическом анализе кода современными линтерами (например, Stylelint), которые выдадут предупреждение о лишних символах.Способ проверить исправление: Удалить px после нулей, сохранить файл и убедиться, что отступы и рамки в браузере не сдвинулись.
